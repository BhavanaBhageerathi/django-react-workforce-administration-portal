# Workforce Administration Portal — Screenshots

This folder contains screenshots demonstrating the user interface and functionality of the Workforce Administration Portal.

## Screenshots Included

* **Login Page:** Shows the login interface for the application.
* **Dashboard:** Displays the main application dashboard.
* **Employee Management:** Demonstrates the employee listing and management interface.
* **Department Management:** Shows the department listing.
* **Project Management:** Demonstrates the project listing and management interface.
* **User Details:** Displays the user details page.

These screenshots illustrate the React frontend and its employee, department, project, and user management features.

## Technologies Used

* React
* JavaScript
* Bootstrap 5
* Django REST Framework
* JWT Authentication
* MySQL
